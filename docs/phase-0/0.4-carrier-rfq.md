# 0.4 — Telephony Carrier: Request for Quotation

**Goal:** get written quotes from **at least 3 licensed Pakistani operators** for outbound calling from the university's own number, then pick one on price, caller ID and written permission for AI-assisted calls.

Telephony is the largest cost line. At Twilio's $0.18/min it's about $3,200 per campaign. A local trunk at around PKR 3/min is about $200 (see [01-cost-estimate.md](../01-cost-estimate.md)).

## 1. Who to ask

| Operator | Product to ask for | Notes |
|---|---|---|
| PTCL / PTCL Business | SIP trunk (or ISDN PRI) with UAN | Most universities already have a PTCL UAN. Ask to extend it |
| Nayatel | Business SIP trunk | Islamabad/Rawalpindi, strong in the north |
| Wateen | Enterprise voice / SIP | Nationwide |
| Multinet | Enterprise voice / SIP | Nationwide |
| Jazz Business | Corporate voice / SIP | Mobile operator. Can be cheaper for on-net Jazz calls |

## 2. RFQ letter (send from the university IT/procurement address)

> **Subject:** Request for quotation: outbound SIP trunk for admission confirmation calls
>
> Dear Sir/Madam,
>
> {University} requests a quotation for an outbound business voice service for our admissions office, with the following requirements:
>
> 1. **SIP trunk** (preferred) or ISDN PRI, terminating to all Pakistani mobile networks (Jazz, Zong, Telenor, Ufone, SCOM) and landlines.
> 2. **Caller ID:** our UAN / landline {number} presented on all outbound calls.
> 3. **Capacity:** 10 concurrent channels minimum, expandable to 20 during campaigns.
> 4. **Volume:** about 20,000 outbound minutes during a 2-week campaign, 1–2 campaigns per year. Low usage otherwise.
> 5. **Calls are placed by an automated voice assistant** (AI) on behalf of the admissions office, to applicants who applied to the university. Please confirm **in writing** that this use is permitted on the service.
> 6. Connection over the internet to our cloud-hosted SIP gateway (static IP, TLS/SRTP if supported), or to an on-premises gateway.
>
> Please quote:
> - Per-minute rate to mobile and to landline (PKR, incl./excl. taxes)
> - Billing increment (per second / 6 s / 60 s)
> - One-time setup fee, monthly rental, per-channel charges
> - Minimum contract period and notice period
> - Technical requirements (codecs, IP whitelisting, registration vs. IP authentication)
> - Any PTA/PSEB registration the university must hold for this use
>
> Kindly reply by {date}.
>
> Regards, {Name}, {Title}, {University} IT Department

## 3. Technical checklist (for the IT engineer on the call with the carrier)

| Item | Requirement |
|---|---|
| Interface | SIP over UDP/TCP/TLS. IP authentication or registration. Static public IP for our SBC |
| Codecs | G.711 (PCMU/PCMA) required. G.729 optional |
| Caller ID | University UAN presented (P-Asserted-Identity / From). Test on all 4 mobile networks |
| DTMF | RFC 2833 (for the future "press 1" features) |
| Channels | ≥ 10 concurrent |
| Fraud control | Outbound restricted to +92 (and the international trunk handled separately), with a daily spend cap |
| Monitoring | CDRs (call detail records) available daily for cost reconciliation |

## 4. Comparing quotes

1. Fill one row per carrier in [`carriers/quotes.csv`](../../carriers/quotes.csv).
2. Run:

```bash
npm run quotes
```

This prints the per-campaign cost for each carrier, **taking the billing increment into account** (60/60 billing on 1.5-minute calls costs about a third more than per-second billing), plus setup and one month's rental. It's sorted cheapest first.

3. Put the chosen rate in `prices.localPkSipPerMinute` in [`src/cost/costModel.ts`](../../src/cost/costModel.ts) and run `npm run cost` to refresh [01-cost-estimate.md](../01-cost-estimate.md).

**Disqualify** any carrier that won't confirm AI-assisted calling in writing, or can't present the UAN as caller ID.

## 5. International numbers (about 10%)

These go through **Twilio** (or Telnyx) using a verified caller ID. Twilio mobile rates are KSA $0.225, UAE $0.2205, Qatar $0.30, Kuwait $0.13, UK $0.029. No RFQ is needed, but register the university's caller ID with Twilio in Phase 1.
