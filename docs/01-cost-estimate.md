# 01 — Cost Estimate

> Prices verified **September 2026**. Exchange rate: **1 USD = 277 PKR** (Sept 2026 average, range 273–281).
> All campaign numbers are generated by [`src/cost/costModel.ts`](../src/cost/costModel.ts). Change an assumption and run `npm run cost` to regenerate.
> Lines marked **ESTIMATE** have no public rate card. Replace them with written quotes during Phase 0.

## TL;DR

| | Option A: managed platform + Twilio | **Option B: managed platform + local PK SIP (recommended)** | Option C: fully custom + local PK SIP |
|---|---:|---:|---:|
| Per campaign (10,000 students) | $5,176 / PKR 1.43M | **$2,280 / PKR 0.63M** | $1,748 / PKR 0.48M |
| Per student | $0.52 | **$0.23** | $0.17 |
| Idle month (no campaign) | $45 | **$85** | $90 |
| One-time build (in-house) | ~$8k / PKR 2.25M | **~$9.4k / PKR 2.6M** | ~$15k / PKR 4.15M |
| Time to first pilot | ~8 weeks | **~10 weeks** | ~16 weeks |
| Year-1 total (build + 1 campaign + 11 idle months) | ~$13.7k | **~$12.6k** | ~$17.7k |
| Each later year (1 campaign + upkeep) | ~$6.5k | **~$4.1k** | ~$4.2k |

**Why B:** telephony is the biggest cost. Twilio charges **$0.18/min** to Pakistani mobiles, while a licensed local operator trunk costs roughly **PKR 2–5/min**. Switching carriers saves about $3,000 per campaign. Building a custom voice stack (C) saves only about $530 more per campaign, but costs about $6k more to build and adds operational risk. It would take more than 10 campaigns to pay back.

A local caller ID (the university's UAN or landline) also gets **noticeably more students to pick up** than a foreign number. That improves results as well as cost.

**Physical server: not needed.** Everything runs in the cloud. The only exception: if your carrier offers only an E1/PRI line and not a SIP trunk, you'd buy one small gateway device (about $500–1,500, one-time) or reuse an office PC running Asterisk.

## 1. Assumptions

| Assumption | Value | Where it comes from |
|---|---|---|
| Students per campaign | 10,000 | Brief |
| Average connected call | 1.5 min | Brief (1–2 min target) |
| Answer on first attempt | 70% | Brief ("~30% need retries") |
| Retry rounds | 2 (3 attempts max) | Configurable in `config/campaign.example.json` |
| Share of remaining students reached per retry | 50% | Typical for spaced retries (different day/time) |
| Unanswered attempts that still get billed (voicemail/IVR) | 20%, 1 billed min each | Conservative |
| Numbers outside Pakistan | 10% (Gulf/UK mostly) | Brief ("mostly PK, some abroad") |
| Carrier billing | Rounded up to whole minutes (60/60) | Twilio and most PK operators. Per-second billing lowers telephony about 25% |
| Agent talk share | ~50% of the call ≈ 450 TTS characters per call-minute | Industry norm for short confirmation calls |
| In-call LLM | ~8 turns/call, ~2.1k input + 60 output tokens per turn, no caching | Conservative (prompt caching would cut this ~40–60%) |

## 6. One-time development cost

These are market estimates (Pakistan, 2026) for reaching a production rollout, covering Phases 0–5 in [07-project-plan.md](07-project-plan.md). They exclude university staff time for the pilot and the legal review.

| Delivery model | A: managed + Twilio | **B: managed + local SIP** | C: fully custom |
|---|---:|---:|---:|
| **In-house** (1 senior backend/voice engineer ≈ PKR 450k/mo + 1 full-stack dev ≈ PKR 250k/mo, plus native-speaker reviewers) | ~3 months → **PKR 2.25M (~$8.1k)** | ~3.5 months → **PKR 2.6M (~$9.4k)** | ~5.5 months → **PKR 4.15M (~$15k)** |
| **Freelancer** (Upwork / local, fixed price) | $5k–10k | $7k–14k | $15k–30k |
| **Pakistani agency** | $12k–25k | $15k–30k | $30k–60k |
| **International agency** | $30k–60k | $40k–75k | $75k–150k |

Notes:
- **In-house** is the cheapest option and keeps the knowledge in-house. It needs someone comfortable with SIP/telephony, which is the riskiest skill.
- **Freelancer** risk: telephony and multilingual testing are where freelance projects stall. Pay by milestone and tie the final payment to the 100-student pilot passing.
- Whichever route you choose, **budget PKR 100–200k for native-speaker review**: scripts and test calls in Punjabi, Pashto, Sindhi and Arabic.

## 8. Ways to cut cost further

1. **Per-second billing.** Ask carriers for per-second or 6/6 billing. This cuts telephony about 25%.
2. **Prompt caching** on the in-call LLM. The system prompt is identical across calls, so caching cuts LLM cost about 40–60%.
3. **SMS/WhatsApp pre-notice** the day before ("Sara from admissions will call you tomorrow"). This raises first-attempt pickup, which means fewer retries.
4. **Cheaper TTS** (Azure) for languages where quality is acceptable. Saves about $220 per campaign, but test the quality first.
5. **Classifier on Haiku.** Saves about $185 per campaign once pilot accuracy is proven.
